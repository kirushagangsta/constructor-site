# TemplateVue.js

## Зависимости

Обязательные зависимости прописаны в package.json

- Используем vue3 + nuxt3, если нужно выключить SSR, пишем ssr: false в конфиге
- В качестве ui-фреймворка испольуем tailwind
- В качестве стора pinia
- Для тривиальных задач lodash

Установка: `npm install`

- vue@3
- nuxt@3
- Используем Composition API для Vue
- @nuxtjs/tailwindcss@latest
- sass@latest --save-dev
- tailwind@latest --save-dev

## Архитектура директорий 

```bash

├── assets
│   ├── scss - директория с файлами стилей
│   │   └── main.scss - основной файл scss, куда импортируются все остальные
│   │   └── common - директория с файлами scss, разбитыми по категориям
│   │       └── **.scss 
│   ├── images - директория с .webp .png картинками
│   ├── svg - директория с .svg картинками
│   │   └── icons - директория с .svg иконками, используемыми в тегах i
│   └── fonts - директория с файлами шрифтов
├── components - директория с vue компонентами
│   └── Ui - директория с компонентами Ui-кита(кнопки, инпуты и прочее)   
├── composables - директория с переиспользуемыми функциями(composables) 
├── layouts - директория с переиспользуемыми паттернами страниц
├── middleware - директория с middleware-функциями для редиректа пользователей 
├── pages - директория с компонентами страниц 
├── plugins - директория с плагинами
├── public - директория со статическими файлами
├── store - директория с модулями стора(pinia)
└── utils - директория со вспомогательными функциями(форматтеры, хелперы и прочее)
```
